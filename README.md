# 오늘의 할 일

브라우저에서 바로 쓰는 간단한 할 일 목록 웹 앱입니다. 설치나 서버 없이 HTML 파일 하나로 동작합니다.

**바로 사용하기:** https://cho5yj-art.github.io/todo-app/

## 기능

- 할 일 추가 (입력 후 Enter 또는 "추가" 버튼)
- 체크박스로 완료 표시
- 더블클릭으로 내용 수정 (Enter 저장, Esc 취소, 내용을 비우면 삭제)
- × 버튼으로 삭제
- 전체 / 진행 중 / 완료 보기 전환과 남은 개수 표시
- 완료한 항목 한 번에 지우기
- 운영체제 설정에 따른 다크 모드

## 데이터 저장

할 일 목록은 브라우저의 localStorage에 자동으로 저장됩니다. 창을 닫았다 열어도 남아 있지만, 그 브라우저에만 저장되므로 다른 브라우저나 기기와는 공유되지 않습니다. 서버로 전송되는 데이터는 없습니다.

## 로컬에서 실행

저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다.

```bash
git clone https://github.com/cho5yj-art/todo-app.git
```

## 배포

`main` 브랜치의 루트 폴더가 GitHub Pages로 배포됩니다. `main`에 push하면 사이트가 자동으로 갱신됩니다.
